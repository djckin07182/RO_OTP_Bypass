# RO TOTP 驗證輔助機

本程式為《仙境傳說》(RO) 的 TOTP 自動輸入輔助工具，具備圖形化介面與背景快捷鍵監聽功能。

## 功能說明

* **快捷鍵自動輸入**：遊戲登入畫面按 `F12`，自動讀取當前遊戲 ID，產生並複製 6 位數 OTP。
* **本地資料加密**：抓取 CPU 序號作為硬體綁定金鑰，以 AES-256 演算法加密帳號資料。
* **圖形化管理**：支援單筆帳號新增/刪除，以及批量匯入/匯出。
* **隱藏與常駐**：點擊最小化 (`-`) 縮小至系統匣背景監聽，點擊關閉 (`X`) 完全結束程式。
* **資料庫位置**：加密後的 JSON 檔案預設存放在 `%LOCALAPPDATA%\RO_Authenticator`。

## ⚠️ 注意事項

* **必須以系統管理員身分執行**：為避免 Windows UIPI 機制或遊戲防護阻擋底層鍵盤監聽，執行 Python 腳本或打包後的 `.exe` 時，**請務必「點右鍵 -> 以系統管理員身分執行」**，否則在遊戲視窗內會無法觸發快捷鍵。
