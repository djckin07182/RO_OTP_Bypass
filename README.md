# RO 登入 TOTP 輔助小工具

一個簡單的 Python 實用腳本。主要功能是讀取 authenticator 的備份檔，並透過全域快捷鍵自動計算並複製 TOTP 驗證碼，省去每次登入都要看手機輸入的麻煩。

## 功能說明
* 讀取 `authenticator.txt` 並自動轉換為綁定本機硬體 (CPU) 的加密格式。
* 程式常駐於系統匣，不佔用工具列空間。
* 在遊戲畫面按下快捷鍵 (預設 F12)，即可自動複製驗證碼到剪貼簿。

## 使用方式
1. 從 Releases 頁面下載打包好的 `RO_OTP_Bypass.exe`。
2. 將你匯出的 `authenticator.txt` 與執行檔放在同一個資料夾。
3. 啟動 `RO_OTP_Bypass.exe`。
4. 進入遊戲需要輸入驗證碼時，按下 `F12`，聽到提示音後按 `Ctrl + V` 貼上即可。

> **註:** 程式首次執行會產生 `config.ini`，若想更改快捷鍵或延遲時間，請關閉程式後修改該檔案再重新啟動。

## 注意事項
1. **防毒誤判：** 因為程式包含「全域鍵盤監聽」功能以偵測快捷鍵，部分防毒軟體 (如 Windows Defender) 可能會跳出警告或誤刪。請自行評估，或將該資料夾加入白名單。
2. **硬體綁定：** 加密後的密碼檔會綁定你當前的電腦硬體。如果更換電腦，舊的加密檔會失效，請重新放入原始的 `authenticator.txt` 讓程式重新加密。
3. **開源聲明：** 本程式無任何連網功能，原始碼完全公開，請安心使用。
